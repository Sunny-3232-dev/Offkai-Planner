# オフ会プランナー 🎉

はじめてのオフ会主催を、企画から告知まで背中を押すツール。

「オフ会を開いてみたいけど、何から始めればいいかわからない」——そんなリベシティ会員のために、
プロフィールを起点に **企画 → 基本情報 → 進行イメージ → 詳細情報 → 画像 → チャット作成 → 告知** までを一気通貫でサポートします。

[Skill Market Creator Pro](https://github.com/Sunny-3232-dev/Skill-Market-Creater-V4)・
[ノウハウ図書館 編集部](https://github.com/Sunny-3232-dev/Google-AI-Studio-KnowHowLib) に続く「背中を押すツール」第3弾です。

## 使い方（8ステップ）

| ステップ | 内容 |
|---|---|
| 1. プロフィール | 自己紹介・興味・**開催したい場所（対面／オンラインの必須選択、対面時は開催エリア）**・既に決まっている企画テーマ（任意）・初主催の不安を入力 |
| 2. 企画案 | **お金の5つのテーマ（貯める・稼ぐ・守る・増やす・使う）とその他で各4案ずつ提案**。プロフィールでテーマを指定した場合はそのテーマに沿った案を5件だけ生成。各案にペルソナ（来てほしい人）つき。ピン留め（灯マーク）は**最大4件**、「別の案を出す」で再生成してもピン留めは残る。カードを**ダブルクリック**するとその企画で次へ直行 |
| 3. 基本情報 | タイトル（AI候補5件）、日時・場所（必須入力）、定員（AIが目安を提案）。オフライン時は**リベシティ公式オフィス（14拠点）をラジオボタンで選択**でき、場所欄・詳細文・サムネプロンプトに連動（オフィス予約の注意つき）。オンライン時は**oVice／Zoom／Google Meet／Teams／その他**から開催ツールを選択。開始時刻は**15分刻み**。完了時に**詳細（公開情報）と画像プロンプト2種を裏で先行生成**し、後のステップの待ち時間を減らす |
| 4. 進行イメージ | 人数×時間からAIが**休憩なしの4〜5項目のシンプルな構成**で生成。行の追加・削除・並べ替え・時間変更が自由（時刻は自動再計算）。**主催者だけが見る進行メモ**で、公開される詳細情報には載らない |
| 5. 詳細（公開情報） | オフ会チャット作成フォームの「詳細（公開情報）」欄にそのまま貼れる文章を、**■イベント・オフ会内容／■参加費用／■参加方法／■募集期限／■注意事項／▶オフ会ガイドライン**の固定テンプレート構成で生成。**標準版／遊び心版のタブ**で2つの版を持てる。遊び心版は**宝塚風・ツンデレ系・オラオラ系・関西弁のプリセット＋自由入力**から文体を選び、標準版の内容（日時・場所・定員）はそのままに文体だけを変えて作る。**書き直しヒントのチップ**（カジュアルに／絵文字増減／初心者歓迎など）をクリックすると要望欄に入り、その内容でAIが書き直す（要望履歴は版ごとに別管理なので、文体が混ざらない）。**どちらの版を使うかは詳細・チャット作成・告知でそれぞれ独立して選べる**（文体そのものはオフ会ごとに1つ）。**マークダウン記法は使わず**プレーンテキストで出力（リベシティが非対応のため）。**チャット作成フォーム用のタグも同時生成**しコピーできる |
| 6. 画像 | チャットアイコン＆告知サムネイルの**画像生成AI用プロンプト**（「あなたはプロのデザイナーです。」始まり）を縦並びで表示。ChatGPT / Gemini 起動リンクつき。アイコンはAIが**キーワードのみ**生成しプロンプト文はコード側で組み立て、サムネイルは**キャッチーなタイトル・日時・場所を画像に焼き込む**プロンプトを生成 |
| 7. チャット作成 | リベシティのオフ会チャット作成フォームへ転記する**ルーム名・定員・タグ・詳細（公開）情報・限定公開情報**をカードごとにコピーできる。遊び心版がある場合は、詳細（公開）情報のカード内で**どちらの版を貼るか**を切り替えられる |
| 8. 告知 | **オフ会チャットURLを入力**した上で、支部チャット向け・つぶやき向けの文章を生成。**公式支部チャット8つ（北海道／東北／関東／北陸・信越／東海／近畿／中国・四国／九州・沖縄）から投稿先を選ぶと「〇〇支部チャットを開く」の直リンク**を表示（プロフィールの開催エリアから自動推定）。オフ会チャットURLが本文に結合され、「この内容でつぶやく」ボタンで本文入力済みのつぶやき画面が開く。こちらにも**標準版／遊び心版のタブ**があり、**詳細（公開情報）とは独立して選べる**。詳細の遊び心版が無くても、標準版を土台に文体だけ乗せて告知の遊び心版を作れる（チャットの説明文は落ち着かせて、つぶやきだけ振り切る、という使い分けができる） |

## 複数オフ会の記録

作ったオフ会は**最大4件**までトップ画面に保存され、「開く」でいつでも編集を再開できます。
オフ会が終了したらゴミ箱ボタンで削除してください（4件埋まっていると新しいオフ会は企画できません）。

## 前工程を変更したときの「作り直しますか？」確認

前の工程の内容を変更してから次に進むと、下流の生成物が前提と食い違っていないか自動チェックし、
食い違っていれば「作り直しますか？」と確認してから作り直します。

- 企画案を選び直す（既存オフ会の企画を変更） → 進行イメージ・詳細情報・画像・告知文をまとめて作り直すか確認
- 基本情報を変更 → 進行イメージ・詳細（公開情報）・画像を作り直すか確認
- 詳細（公開情報）を変更 → 展開用の文章（支部チャット・つぶやき）を作り直すか確認

進行イメージは主催者専用のメモになったため、進行イメージだけを変更しても詳細（公開情報）の作り直しは不要です。

「いいえ」を選んだ場合は古い内容のまま次に進み、以後は同じ変更点について再度は聞きません（さらに変更が入るまで）。

## バックアップ（エクスポート／インポート）

データはブラウザのlocalStorageにのみ保存されるため、**キャッシュ削除・ブラウザ変更・別端末への移行で消えます**。
トップ画面下部の「バックアップを保存」でプロフィール・オフ会・生成結果一式をJSONファイルとしてダウンロードでき、
「バックアップを読み込む」でそのファイルから復元できます（読み込むと現在のデータは上書きされます）。

- APIキーはバックアップファイルに**含まれません**（ファイル共有・誤送信での漏洩防止）
- 別ブラウザ・別端末への引っ越しにも使えます

## 技術構成

- React 19 + Vite + TypeScript + Tailwind CSS 4
- Google Gemini API（`@google/genai` / gemini-2.5-flash）
- ホスティング: Google AI Studio（APIキーはセッションから自動取得）
- データ保存: ブラウザのlocalStorageのみ（サーバー送信なし）

## 開発

```bash
npm install
# .env.local に GEMINI_API_KEY=... を設定（ローカル開発用）
npm run dev
```

- 型チェック: `npm run lint`
- ビルド: `npm run build`
- AI Studioアップロード用zip生成: `npm run pack`
  （git管理下のソースのみを `offkai-planner-to-aistudio.zip` に固めます。常に同名で上書きされるため、これが最新版です）

## 初めて使う人の準備（AIが動かないとき）

AI Studioは開いているGoogleアカウントのキーを自動で渡しますが、**そのアカウントでAPIキーを一度も作っていないと権限エラー（PERMISSION_DENIED）になります**。
また、アカウントに紐づくGoogle Cloudプロジェクト側が使えない状態だと、同じアプリでもアカウントによって動いたり動かなかったりします。

その場合は、各自が自分のキーを用意すれば使えます。

1. 画面右上の鍵アイコンを開く
2. 「自分のAPIキーを無料で作る」から [aistudio.google.com/apikey](https://aistudio.google.com/apikey) を開き、「Create API key」でキーを作る
3. 作ったキー（`AIza…`）を鍵アイコンの入力欄に貼って保存

キーはそのブラウザのlocalStorageにのみ保存され、外部には送信されません（バックアップファイルにも含まれません）。

権限エラーが出たときは、画面に **`［Googleからの応答］`** としてGoogleが返した原文が表示されます。
「Generative Language API has not been used in project …」ならそのプロジェクトでAPIを有効化、
「Your project has been denied access」ならそのプロジェクトはGoogle側でブロックされているため別のキーを使ってください。

## APIキーの解決順序

1. 画面右上の鍵アイコンから手動保存したキー（localStorage）
2. 環境変数 `API_KEY` / `GEMINI_API_KEY`（AI Studioがビルド時に用意するキー・ローカル開発用キー）
3. AI Studioセッション任せ（キーを渡さず `new GoogleGenAI({})` で初期化し、SDKにセッション認証させる）

2〜3の順序は、複数アカウントで動作実績のある SkillMarket Creator（PJ013/PJ015）と同じです。
以前は `window.aistudio.apiKey` を自前で取り出して渡していましたが、この方式は
アカウントによって PERMISSION_DENIED になるため廃止しました。

**手動保存したキーが最優先**です（無料枠の上限を別アカウントのキーで回避できるようにするため）。
そのため古いキーや別アカウントのキーが保存されたままだと、AI Studio側が正常でも権限エラーが出続けます。
鍵アイコンのパネルといずれかのキー起因エラーには「いま使っているキー」の出所が表示され、
手動保存キーを使っている場合はワンクリックでAI Studioのキーに戻せます。

## プライバシー

入力されたプロフィール・生成結果はすべてブラウザのlocalStorageにのみ保存されます。
独自サーバーへの送信はありません（AI生成時にGoogle Gemini APIへプロンプトが送信されます）。
